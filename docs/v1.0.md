# NEXUS 1.0

NEXUS 1.0 is the ecosystem foundation release.

## Language

Working core: variables, mutability, const bindings, functions, recursion, structs, enums, arrays, pointers, match, while, break/continue, `for ... in a..b`, compound assignments, string operations, C ABI declarations and native LLVM code generation.

## Runtime

Working runtime families include terminal IO, files, environment, memory allocation, HTTP GET facade, lightweight JSON object field extraction, dynamic SQLite loading, SHA-256 helper, SDL/OpenGL graphics, audio, UI, ECS, scenes, particles, physics, textures, fonts and OBJ models.

## Tooling

`nexus fmt`, `nexus lint`, `nexus doc`, `nexus bench`, `nexus test`, `nexus editor`, `nexus lsp`, and the local `nexus pkg` workflow are included.

## Cross compilation

The compiler exposes explicit target triples for Linux, Windows, macOS, Android and WASM. Native linking still depends on a matching local toolchain and sysroot.

## Advanced roadmap

Full generic monomorphization, trait dispatch, closures/async lowering, a visual scene editor, complete JSON/HTTP server stacks, and a remote package registry remain post-1.0 work.
